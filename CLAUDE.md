# MFE 230GA Final Project

Evaluate an active investment strategy (brief: `MFE230GA_Final_Project_2025.pdf`). Current strategy: state-dependent green-minus-brown industry returns conditioned on climate-transition attention and macro regimes. Summary of results so far is in `writeup.pdf`.

## Environment

Managed with uv. Run everything through `uv run` from the repo root; add dependencies with `uv add <pkg>`, never pip.

## Notebooks and scripts

Every notebook in `notebooks/` has a paired jupytext percent-format script with the same name (`foo.ipynb` <-> `foo.py`), configured in `jupytext.toml`. The notebook is for the user; the script is for Claude.

- Read and edit the `.py` script, never the `.ipynb` directly.
- Use the Read/Edit/Write tools on scripts, not sed or other Bash edits. A hook in `.claude/settings.json` runs `jupytext --sync` before Read/Edit (pulls in edits the user made in the notebook) and after Edit/Write (pushes script edits into the notebook, keeping outputs of unchanged cells).
- If a script is changed outside those tools, run `uv run jupytext --sync notebooks/<name>.py` afterwards.
- To add a notebook, write `notebooks/<name>.py` in percent format (`# %%` code cells, `# %% [markdown]` text cells); the hook creates the `.ipynb`.
- Scripts must also run as plain Python: import `display` from `IPython.display` rather than relying on the Jupyter builtin.
- Test a change with `MPLBACKEND=Agg uv run python notebooks/<name>.py`.

## Layout

- `data/`: input CSVs (FF49 industry returns, FF3 factors, industry emissions intensity, macro series). Treat as read-only.
- `papers/`: reference literature.
- `ai/`: log of AI prompts used for the deliverable, one file per interaction, following the template in `ai/README.md`. When the user asks to record a prompt, add a file there.
- `outputs/figures/`, `outputs/tables/`: generated by the notebooks; paths are set in the setup cell via `ROOT`, `FIGURES`, `TABLES`.

## Deliverable requirements to keep in mind

The report needs style/risk factor exposures, performance over full sample / post-2010 / recent 12-18 months, turnover and costs, robustness checks, and at least three documented ChatGPT interactions (prompt, summarized output, critical evaluation). If the results don't support alpha, the report must say "Do not implement".
