# AI Prompts

Record of the AI interactions used for the project. The brief requires at least three substantial ones (idea generation, coding support, robustness design), each documented with the prompt, a summary of the output, and a critical evaluation.

Add one file per interaction, numbered in order: `01_idea_generation.md`, `02_coding_support.md`, and so on. Use this template:

```
# <Title>

Tool: <e.g. ChatGPT (model), Claude>
Date: <YYYY-MM-DD>
Purpose: <idea generation / coding support / robustness design / other>

## Prompt

<exact prompt text, including follow-ups>

## Output summary

<what the model returned, summarized; paste key excerpts if useful>

## Evaluation

<what was useful, what was wrong or missing, and how the output was adapted>
```
